# 🛒 E-Commerce Product Recommendation System

## 📌 Project Overview
This project is a content-based recommendation system that suggests similar products based on product name, category, and description.

---

## ⚙️ Tech Stack
- Python
- Pandas
- Scikit-learn

---

## 🧠 How it works
- Combines product features
- Uses TF-IDF vectorization
- Calculates cosine similarity
- Recommends similar products

---

## 🚀 How to run

```bash
pip install -r requirements.txt
python main.py
